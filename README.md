# Лабораторная работа: Иерархия персонажей в игре (ООП на C++)

Цель работы — продемонстрировать основные принципы объектно-ориентированного программирования на языке C++:

- наследование
- полиморфизм
- инкапсуляцию
- переопределение методов (virtual)
- обработку исключений
- юнит-тестирование с использованием assert

## Описание классов

| Класс       | Базовый класс     | Особенности поведения при получении урона (TakeDamage)                  | Дополнительный параметр |
|-------------|-------------------|-----------------------------------------------------------------------|--------------------------|
| GameCharacter | —                | чисто виртуальный метод TakeDamage, виртуальный DisplayInfo           | —                        |
| Warrior     | GameCharacter    | уменьшает входящий урон на половину силы (strength / 2)               | strength                 |
| Mage        | GameCharacter    | сначала расходует ману (1:1), только потом здоровье                   | mana                     |
| Archer      | GameCharacter    | с вероятностью 50% урон полностью блокируется (уклонение)            | agility                  |

## Реализованные возможности

- Конструкторы с параметрами
- Геттеры и сеттеры (с проверкой корректности значений)
- Выброс исключений при попытке установить некорректные значения (strength, mana, agility ≤ 0)
- Виртуальный метод `DisplayInfo()` — красивая текстовая информация о персонаже
- Перегруженный виртуальный метод `TakeDamage(int damage)`
- Демонстрация полиморфизма через массив указателей на базовый класс
