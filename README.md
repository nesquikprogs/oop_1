# Лабораторные работы по Объектно-Ориентированному Программированию (ООП) на C++

В этом репозитории собраны **лабораторные работы по дисциплине "Объектно-Ориентированное Программирование"**, выполненные на языке **C++**.  

Цель лабораторных — закрепить и продемонстрировать практическое понимание принципов ООП, таких как:
- **Инкапсуляция** — скрытие внутреннего состояния объектов и предоставление методов для работы с ними.
- **Наследование** — создание новых классов на основе существующих, расширение функциональности.
- **Полиморфизм** — возможность работы с объектами разных типов через единый интерфейс.
- **Абстракция** — моделирование реальных объектов и систем через классы и объекты.  

## Особенности реализации

- **Все лабораторные реализованы с использованием принципов ООП**: классы, наследование, полиморфизм и инкапсуляция.  
- Программы построены **пошагово**, что позволяет наглядно наблюдать работу алгоритмов и поведение объектов.  
- Используется **C++** — язык, который позволяет глубоко изучить основы ООП и работу с памятью.  

---

## Цель и образовательная ценность

- Понимание основных принципов объектно-ориентированного программирования.  
- Навыки проектирования классов и объектов для решения реальных задач.  
- Опыт реализации алгоритмов и систем с различной сложностью поведения через ООП.  
- Возможность пошаговой визуализации и анализа работы алгоритмов.
