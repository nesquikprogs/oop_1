# Lab Work 3 - Array Program

## Описание

Лабораторная работа посвящена работе с массивами в C++.  
В программе реализованы функции для:

- Заполнения массивов случайными числами (вектор `std::vector` и обычный массив);
- Вывода массивов на экран;
- Вычисления произведения элементов массива;
- Чтения и записи массивов в файлы;
- Тестирования функций с использованием `assert`.

Программа демонстрирует работу как с динамическими массивами, так и с векторами STL.  
Также реализована обработка ошибок при работе с файлами через исключения (`try-catch`).

## Файлы лабораторной

- `array_utils.h` — заголовочный файл с объявлениями функций для работы с массивами.  
- `array_utils.cpp` — реализация функций для работы с массивами.  
- `main.cpp` — демонстрационный файл для тестирования всех функций:  
  - Заполнение массивов случайными числами  
  - Вывод массивов  
  - Чтение и запись в файлы  
  - Вычисление произведения элементов  
  - Обработка ошибок  

## Использование

1. Компилируйте проект в Visual Studio как обычный C++ проект.  
2. Запустите программу и следуйте инструкциям в консоли:  
   - Введите размер массива;  
   - Укажите минимальное и максимальное значение элементов;  
   - Программа автоматически создаст массив, сохранит его в файл и выведет произведение элементов.
