Описание

АДТ GameCharacter представляет собой модель игрового персонажа в ролевой игре. Персонаж характеризуется именем, количеством здоровья и уровнем. АДТ предоставляет операции для создания персонажа, получения и изменения его характеристик, нанесения урона, вывода информации и сравнения персонажей.

Данные





name: строка (тип: string)





Описание: Имя персонажа.



Ограничение: Не может быть пустой строкой.



health: целое число (тип: int)





Описание: Текущее здоровье персонажа.



Ограничение: Должно быть больше 0.



level: целое число (тип: int)





Описание: Уровень персонажа.



Ограничение: Должен быть не меньше 1.

Операции





Создание персонажа по умолчанию





Сигнатура: GameCharacter()



Описание: Создает персонажа с параметрами по умолчанию: имя = "Неизвестный", здоровье = 100, уровень = 1.



Результат: Новый объект GameCharacter.



Исключения: Нет.



Создание персонажа с параметрами





Сигнатура: GameCharacter(name: string, health: int, level: int)



Описание: Создает персонажа с заданными именем, здоровьем и уровнем.



Входные данные:





name: строка, не пустая.



health: целое число, больше 0.



level: целое число, не меньше 1.



Результат: Новый объект GameCharacter с указанными значениями.



Исключения:





Если name пустое, выбрасывается исключение: "Имя не может быть пустым".



Если health ≤ 0, выбрасывается исключение: "Показатель здоровья не может быть ниже или равняться 0".



Если level < 1, выбрасывается исключение: "Уровень должен быть не меньше 1".



Получение имени





Сигнатура: GetName() → string



Описание: Возвращает имя персонажа.



Результат: Текущее имя персонажа (строка).



Исключения: Нет.



Получение здоровья





Сигнатура: GetHealth() → int



Описание: Возвращает текущее здоровье персонажа.



Результат: Текущее здоровье персонажа (целое число).



Исключения: Нет.



Получение уровня





Сигнатура: GetLevel() → int



Описание: Возвращает текущий уровень персонажа.



Результат: Текущий уровень персонажа (целое число).



Исключения: Нет.



Установка имени





Сигнатура: SetName(newName: string) → bool



Описание: Устанавливает новое имя персонажа.



Входные данные: newName — строка, не пустая.



Результат: true, если имя успешно установлено.



Исключения: Если newName пустое, выбрасывается исключение: "Имя не может быть пустым".



Установка здоровья





Сигнатура: SetHealth(newHealth: int) → bool



Описание: Устанавливает новое значение здоровья персонажа.



Входные данные: newHealth — целое число, больше 0.



Результат: true, если здоровье успешно установлено.



Исключения: Если newHealth ≤ 0, выбрасывается исключение: "Показатель здоровья не может быть ниже или равняться 0".



Установка уровня





Сигнатура: SetLevel(newLevel: int) → bool



Описание: Устанавливает новый уровень персонажа.



Входные данные: newLevel — целое число, не меньше 1.



Результат: true, если уровень успешно установлен.



Исключения: Если newLevel < 1, выбрасывается исключение: "Уровень должен быть не меньше 1".



Вывод информации





Сигнатура: DisplayInfo() → string



Описание: Возвращает строковое представление информации о персонаже.



Результат: Строка в формате:

Имя: <name>
Здоровье: <health>
Уровень: <level>



Исключения: Нет.



Нанесение урона





Сигнатура: TakeDamage(damage: int) → bool



Описание: Уменьшает здоровье персонажа на заданное значение.



Входные данные: damage — целое число, больше 0.



Результат: true, если здоровье успешно уменьшено.



Исключения:





Если damage ≤ 0, выбрасывается исключение: "Нанесенный урон не может быть меньше или равен нулю".



Если здоровье станет меньше 0 после вычитания урона, выбрасывается исключение: "Здоровье не может стать меньше нуля".



Сравнение персонажей





Сигнатура: operator==(other: GameCharacter) → bool



Описание: Сравнивает текущего персонажа с другим по всем атрибутам (имя, здоровье, уровень).



Входные данные: other — другой объект GameCharacter.



Результат: true, если все атрибуты совпадают, иначе false.



Исключения: Нет.

Инварианты





Имя персонажа (name) никогда не является пустой строкой.



Здоровье персонажа (health) всегда больше 0.



Уровень персонажа (level) всегда не меньше 1.

Исключения





Пустое имя при создании или установке имени: "Имя не может быть пустым".



Здоровье ≤ 0 при создании или установке здоровья: "Показатель здоровья не может быть ниже или равняться 0".



Уровень < 1 при создании или установке уровня: "Уровень должен быть не меньше 1".



Урон ≤ 0 при вызове TakeDamage: "Нанесенный урон не может быть меньше или равен нулю".



Здоровье < 0 после нанесения урона: "Здоровье не может стать меньше нуля".
