# Lab Work 1 - Working with Git

## Описание

Первая лабораторная работа посвящена изучению работы с системой контроля версий **Git**.  
Цель работы — освоить базовые операции: создание репозитория, коммиты, работа с `.gitignore`, управление ветками и пуш изменений на GitHub.

## Файлы лабораторной

- `main.cpp` — пример программы на C++ для тестирования репозитория (вывод "Hello, World!" и "Hello, Dear Friend").  
- `.gitignore` — файл для игнорирования временных и мусорных файлов, таких как конфигурации Visual Studio, логи и папки с временными файлами.  
- `Отчет по работе с git.docx` — отчёт по лабораторной работе, в котором описаны шаги выполнения и анализ работы с Git.

## Основные цели и навыки

- Создание и инициализация Git-репозитория.  
- Настройка `.gitignore` для игнорирования временных файлов.  
- Совершение коммитов (`git commit`) и отправка изменений на GitHub (`git push`).  
- Работа с удалённым репозиторием и решение конфликтов.  
- Организация файловой структуры проекта.

## Примечание

Эта лабораторная является базовой и подготовительной для последующих лабораторных работ по дисциплине "Объектно-ориентированное программирование на C++".
