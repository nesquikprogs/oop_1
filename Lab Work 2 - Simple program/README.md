# Lab Work 2 - Simple Program

## Описание

Вторая лабораторная работа посвящена разработке простой программы на C++, демонстрирующей навыки:

- Создания и использования функций;
- Работа с заголовочными файлами и модулями;
- Проверка корректности вычислений с помощью assert;
- Ввод/вывод данных с форматированием.

Программа решает задачу вычисления второго катета и радиуса вписанной окружности в прямоугольном треугольнике.

## Файлы лабораторной

- `main.cpp` — основной файл программы, содержит ввод данных, вызов функций для расчётов и вывод результатов.  
- `triangle.cpp` — реализация функций:
  - `calculateLeg(double hypotenuse, double leg1)` — вычисление второго катета по теореме Пифагора;
  - `calculateRadius(double hypotenuse, double leg1, double leg2)` — вычисление радиуса вписанной окружности;
  - `runAssertions()` — тестирование функций на корректность.  
- `triangle.h` — заголовочный файл с объявлениями функций для работы с треугольником.

## Ход работы

1. Пользователь вводит длину гипотенузы и одного катета.  
2. Программа проверяет корректность введённых данных: все стороны положительные, катет меньше гипотенузы.  
3. Вызываются функции для вычисления второго катета и радиуса вписанной окружности.  
4. Выводятся результаты с фиксированным числом знаков после запятой.  
5. Для проверки корректности работы используются assert-тесты.
